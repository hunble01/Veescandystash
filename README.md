# Vee’s Candy Stash — website

*Every Sweet Tooth Needs a Stash.*

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Where things live

- `docs/Vees_Candy_Stash_Claude_Code_Handoff.md`: the business brief
- `docs/decisions.md`: what has been decided and what is still open
- `src/config/site.ts`: contact details, policies, announcement bar, logo
- `src/data/`: products, occasions, FAQ (moves to Sanity in Phase 2)
- `src/app/globals.css`: brand colours and design tokens
